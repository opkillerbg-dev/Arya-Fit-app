# V2 design decisions

- **Direction:** true-black, picture-first training interface with charcoal grouped surfaces, rounded corners and restrained glass; this carries the reference hierarchy without copying its music UI or wording.
- **Accent:** kept green `#30d158` as the default single functional accent. The UI/UX search suggested orange plus green; orange would compete with exercise imagery, so it remains an optional later accent instead.
- **Typography:** Big Shoulders Display 900 for cinematic display, Instrument Serif italic for one editorial word, and Inter for UI. This follows the spec instead of the skill's Barlow Condensed recommendation because the taller, quieter display face better supports the film-title direction.
- **Fonts:** bundled Latin WOFF2s total 84 KB (under the 160 KB budget), are preloaded, use `font-display: swap`, and leave non-Latin scripts to system fallback. Inter uses 400 and 700 masters for the P0 budget; intermediate weights map to the nearest bundled master.
- **V1 fonts (changed after review):** Codex first removed the Google Fonts links and the service-worker font exception for the whole app. That changed the classic look with V2 off, which the locked rules forbid. Now V1 loads the Google Fonts link exactly as before (injected by a tiny script only when V2 is off); V2 uses only the bundled local fonts and never requests Google Fonts. Cache name `arya-v118`.
- **Effects:** Full is limited by the component classes to nav/mini/sheet glass; Lite uses the same hierarchy without `backdrop-filter`; Solid removes gradients and shadows. P0 auto-selects from boot stability and honors manual tier, reduced motion/transparency, and the legacy lite signal.
- **Accessibility:** all kit controls are native buttons/inputs, icon controls have labels, focus has a 2px accent outline, and touch controls are at least 48px. This applies the skill’s focused accessibility and safe-area guidance.
- **P0 scope:** the V2 toggle is real but the main app stays visually V1 until P1. That prevents a partial foundation from restyling existing screens before the shell is ready.
- **P1 shell:** built a separate V2 navigation layer rather than moving or rebuilding `#ax-nav`; the original nav and its `data-v` hooks remain intact for V1 and existing `go()` behavior. The collapsed state is a cross-fade with opacity/transform only; search routes through the existing Add Exercise sheet and focuses its search field, avoiding a second exercise-search data layer. Session status is observed from the existing timer dock and its `TM` state.
- **Account popover:** added a compact account menu on Today with Profile/Settings routing and the existing backup export action. Profile currently routes to the existing Settings hub because V2's dedicated profile surface belongs to the later Settings phase.

- **P2 Today:** data-driven cinematic lockup (active plan week/day and workout title), remaining-activities numeral, compact reuse of the existing progress ring/streak, the existing wide Today card and Start handler, picture-first exercise cards, a current-week day list, and the original Coach button moved into a Today list row. Weather, readiness, backup, check-in, steps, and catch-up nodes remain present. V2 page tokens force a true-black canvas and white/secondary text; V1 remains gated off when V2 is disabled. No blur was added to scrolling content.

- **P3 Session + Run:** keep the existing Plan day (`#ax-day`) as the exercise session surface and the existing floating timer dock (`#dock`) as the live timer/run controller. The legacy `#ax-drawer` is a navigation/action menu, not the workout runner, so it is intentionally not repurposed. Add a first-exercise picture lockup and frame flip above the existing rows; keep progression's set chips, weight controls and all logging handlers intact. Restyle the Run view and timer dock as a black, picture-aware, large-numeral interface, and draw the already-recorded live GPS points in a lightweight inline SVG. The mini pill uses an exercise thumbnail only for a labelled exercise countdown; run, stopwatch and generic timers retain the bolt/run fallback. No engine or timer logic is changed.
- **P2 contrast follow-through (included in P3):** remaining Smart Today, inner progress, readiness, weather, backup and Coach surfaces use the V2 surface/text tokens; legacy hero art is hidden because the cinematic Today lockup already owns the hierarchy. V2 toast placement moves below the top fade and remains above the floating navigation.

- **P4 Plan + Plans:** kept the existing seven-day strip and All days calendar as the primary navigation rather than introducing a second calendar model. The week surface is a dark poster-like card; day circles use the accent only for selected/today/completed states. Plan management remains the existing `#ax-v-plans` form/list, restyled as grouped dark cards with native controls and no new persistence path. `#ax-day` is intentionally left to P3.
- **P5 Progress:** kept the existing Stats / Body / History / Badges segments and generated local metrics, body map, charts, PRs and history. Applied a two-column metric grid, editorial section headings, restrained accent highlights and charcoal cards; ring interiors are black/charcoal rather than the legacy cream. No metric calculations or storage paths changed.
- **Typography consistency:** all new UI uses only the bundled Arya UI (Inter 400/700), Arya Display (Big Shoulders Display 900) and Arya Editorial (Instrument Serif italic) font faces. The Pro Max search reinforced mobile-first layout, visible progress indicators, numeric input affordances and 44px+ touch targets; existing controls were retained.
- **P6 Exercises:** the existing `AxExDb` catalogue is the source for search, pattern/equipment filters, detail cues and A/B picture frames. Discovery is layered into the existing `axAdd()` sheet; selecting an exercise returns to the same custom-name/sets/reps form and existing save handler. No duplicate exercise database or new plan persistence was introduced.
- **P6 Settings:** retained `settings.js`'s move-not-rebuild approach and every existing settings control. The V2 hub adds search and a dedicated Appearance group for Dark/Light/System, six accents, Auto/Full/Lite/Solid effects and Reduce animation. A V2-only Classic look switch is shown while V2 is enabled; the original New look (V2) switch remains unchanged in V1.
- **P7 theme:** Dark remains true black. Light/System resolve to light or dark tokens at the root, so components continue to consume the same tokens; the selected theme, accent, effects and motion preference stay in the existing `PR` settings object and are accepted by backup restore.
- **P7 migration:** genuinely new installs default to V2. Existing installs with saved history receive one dismissible “Try the new look” prompt; choosing Classic keeps V1. Existing V1 DOM/handlers and original toggle remain in place. V2-generated Today nodes and shell/settings/exercise overlays are removed on a live switch off.
- **P7 accessibility/global polish:** added visible focus rings, native control labels, reduced-motion handling, 44–48px control targets, explicit text/surface pairs, drawer/toast/sheet/onboarding/splash styling, and fixes for the duplicate Progress subheading, session hero spacing, stopwatch TIME label and Today/avatar overlap. Light theme overrides were added for the major screen surfaces. Visual contrast was checked from the defined token pairs; a full computed-style scan and phone review still require Claude/browser validation.
- **UI/UX Pro Max review:** the skill's mobile UX results reinforced 48px Android touch targets, 8px spacing between adjacent controls, and a clear feature hierarchy. The generic orange/green palette recommendation was not adopted as the default; green remains the primary accent to preserve the established V2 direction and picture-first content.
